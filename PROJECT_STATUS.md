# Chat AI TPios — Project Status

## Chat Voice avatar — Alina (2026-11-10)

### Current implementation
- Chat Voice uses AlinaAvatarView and loads Alina.usdz from ChatAI/Resources.
- USDZ resource is included in the app bundle; runtime geometry and animation diagnostics are pending.
- Alina's runtime mesh, skeleton, skinning, and animation details have not yet been validated on device.
- No facial rig or blendshape requirement; current test focuses on full-body display and skeletal animation.
- Animation playback remains disabled until Alina's imported clips are inspected and tested on device.
- Alina uses bounds-based auto-fit: measure `visualBounds` in model-local coordinates, normalize body height to 1.45 units, place the feet at Y=0, and set the anchor to the negative half-height so the body midpoint is centered vertically; anchor depth remains Z=-2.8.
- Zoom now scales a dedicated child pivot around the fitted model center instead of scaling the model root position during every pinch. Alina zoom storage is v1 (default 2.5) to reset the previously persisted 4.5 value; pinch range remains 0.7–4.5. Validate full-body framing and zoom centering on device.
- Tap Alina to start or end the Gemini Live voice conversation.
- Chat Voice uses Gemini Live as its only conversation engine for both microphone speech and typed text. Typed text is sent through the active Live WebSocket as a history-preserving `clientContent` user turn with `turnComplete: true`; the same Live session generates the spoken audio response (`responseModalities: AUDIO`).
- Typed messages are accepted only after the user taps Alina and Gemini Live reaches `.live`; the input is added to the on-screen transcript and sent directly to that session. No provider chat API, Azure TTS, or iOS TTS is used in Chat Voice.
- Existing diagnostic log and copy button are retained.

### Build pipeline
- Codemagic has one build workflow: `ios-unsigned`.
- It validates `ChatAI/Resources/Alina.usdz`, builds the Release app, packages it as `chat-ai-tpios-<BUILD_NUMBER>.ipa`, and verifies the IPA archive.
- The Codemagic artifact filter includes only `chat-ai-tpios-*.ipa`; no separate ZIP, TXT, or log artifact is published. Build logs remain available in the Codemagic build log view.
- The IPA is unsigned because code signing is disabled in this workflow; installation on a physical iPhone may require signing.

### Protected functionality
- `LiveVoice.swift` now contains the minimal `sendText` entry point for Gemini Live text input. Preserve its existing microphone, WebSocket, audio playback, and session lifecycle code. Do not modify `ChatViewModel.swift` or `Services.swift` for this feature.
- Preserve audio pipeline, chat history, Text Chat, and Chibi Chat.
- Keep the Chat Voice diagnostic log and copy-log button.
